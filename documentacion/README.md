# Mivank Fintech — Next Tier Digital Banking

Plataforma premium para la gestión centralizada de préstamos, clientes y activos financieros, diseñada con arquitectura **Zero Trust** y estética **Chation Premium**.

## 🚀 Stack Tecnológico
- **Frontend**: Next.js 15 (App Router)
- **Estilos**: Tailwind CSS + Custom Design System
- **Backend/DB**: Supabase (PostgreSQL, Auth, Storage)
- **Iconografía**: Lucide React
- **Animaciones**: Framer Motion
- **Gráficos**: Recharts

## 📐 Arquitectura
- **Mobile-First**: Optimizado para dispositivos móviles con diseño de navegación tipo "píldora".
- **Glassmorphism**: Interfaz translúcida y moderna.
- **Seguridad**: RLS (Row Level Security) estricto y auditoría de logs.

## 📁 Estructura del Proyecto
- `/src/app`: Rutas del servidor y layouts.
- `/src/components`: UI shared components.
- `/diseño`: Manual de marca y assets visuales.
- `/documentacion`: Guías de usuario y técnicas.

## 🛠 Instalación
```bash
npm install
npm run dev
```
Consulte la [Guía de Despliegue](./DEPLOY_GUIDE.md) para entorno de producción.
