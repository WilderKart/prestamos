# Mapa del Sitio — Mivank v2.0

## 📂 Acceso Público
- `/login` (Autenticación Segura)

## 👤 Área Capitán (`/capitan/`)
- `/` — Resumen General (KPIs, Gráficos)
- `/clientes` — Directorio de Clientes (CRUD)
- `/clientes/[id]` — Ficha del Cliente (En progreso)
- `/pagos-pendientes` — Validación de Reportes de Pago
- `/amortizaciones` — Control de Cuotas y Vencimientos
- `/onboarding` — Flujo de Registro Paso a Paso (CRUD Avanzado)

## 🛡 Área Admin (`/admin/`)
- `/` — Panel de Control Maestro
- `/usuarios` — Lista de Usuarios (Asignar Roles)
- `/capitanes` — Gestión de Equipos de Venta
- `/prestamos` — Visibilidad Global de la Cartera
- `/pagos` — Historial Completo de Transacciones
- `/configuracion` — Parámetros de Sistema
- `/logs` — Auditoría de Seguridad

## 🔌 Componentes Globales
- **Header**: Branding, Notificaciones, Perfil, Logout.
- **BottomNav**: Barra Flotante para Navegación Móvil.
- **Toast**: Sistema de Avisos en Real-time.
