# Manual de Marca — Mivank Fintech

## 1. Identidad Visual
Mivank proyecta una imagen de **seguridad, sofisticación y agilidad**. La estética "Chation Premium" se basa en el minimalismo suizo con toques de lujo moderno (Gold & Black).

## 2. Logotipo
- **Símbolo**: Una "M" geométrica, sólida y dinámica.
- **Colores**: Negro (#000000) y Amarillo Dorado (#F5C518).
- **Uso**: Siempre con suficiente aire alrededor. En fondos oscuros usar la versión dorada; en fondos claros la versión negra o combinada.

## 3. Paleta de Colores
| Uso | Color | Hex | Aplicación |
| :--- | :--- | :--- | :--- |
| **Primario** | Negro | `#000000` | Headers, Botones, Texto Principal |
| **Acento** | Dorado Mivank | `#F5C518` | Íconos, Highlights, Estados Activos |
| **Fondo** | Gris Extra-Claro | `#F3F4F6` | Superficie principal de la App |
| **Superficie** | Blanco Glass | `#FFFFFF` | Tarjetas con blur y sombras suaves |
| **Éxito** | Verde Esmeralda | `#22c55e` | Pagos aprobados, Cartera sana |
| **Peligro** | Rojo Intenso | `#ef4444` | Mora, Errores, Acciones críticas |

## 4. Tipografía
- **Principal**: Inter (Google Fonts)
- **Estilos**: 
  - **Black (900)**: Para títulos de sección y KPIs.
  - **Bold (700)**: Para nombres de clientes y botones.
  - **Medium (500)**: Para textos de apoyo y leyendas.
  - **Inter (Variable)**: Para todo el cuerpo de texto.

## 5. Componentes UI
- **Glassmorphism**: Tarjetas blancas con opacidad 0.8, backdrop-filter blur 12px y sombras `0 20px 40px rgba(0,0,0,0.05)`.
- **Bordes**: Radio de curvatura de `24px` para un look moderno y amigable.
- **Iconografía**: Lucide React, trazo de 2.5px para estados activos, 2px para estados inactivos.
